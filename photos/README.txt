Photography for the client view, one per job type:

  architectural.jpg   cable balustrade, mesh barrier or green wall
  marine.jpg          yacht mast or rigging
  fabrication.jpg     stainless railing or custom part

The current files are free stock stand-ins (see CREDITS.txt). To use Skymaze's
own photos, replace the files and keep the same names. Landscape, about
1600 x 1280 px (5:4), under 500 KB each, works best.
If a file is removed, the page shows the line drawing for that job type instead.
